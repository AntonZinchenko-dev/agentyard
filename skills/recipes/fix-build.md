Починить сборку, типы, линтер.

1. Работай от вывода проверки: каждая ошибка — файл и строка. Группируй задачи по файлам (одна задача — один-два файла).
2. Чини причину, а не глуши: никаких any, @ts-ignore, # type: ignore, //nolint, unsafe — только если иначе нельзя, с комментарием почему.
3. Ошибки, которые были до прогона, программа уже знает — сосредоточься на тех, о которых просили.
