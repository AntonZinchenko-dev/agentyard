Тёмная тема.

1. Одна задача на общий файл стилей: цвета вынести в переменные :root (--bg, --text, --muted, --border, --primary), правила перевести на var(...).
2. В том же файле — @media (prefers-color-scheme: dark) { :root { … тёмные значения … } }. Контраст текста к фону не ниже 4.5:1.
3. Страницы и разметку не трогать: тема меняется только через CSS.
