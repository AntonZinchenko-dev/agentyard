Адаптивная вёрстка.

1. Правки в общем CSS: медиазапросы @media (max-width: 768px) { … } рядом с правилами, которые меняются.
2. Таблицы на узком экране — горизонтальная прокрутка обёртки (overflow-x: auto), а не сжатие колонок; формы — в одну колонку; кнопки — не уже 44px по высоте.
3. Убрать фиксированные ширины (width: 1100px) в пользу max-width + width: 100%.
