Переименование по всему проекту.

1. Если однотипных файлов много — одна задача с правкой по образцу (similar), образец — один файл.
2. Имя меняется во всех написаниях (kebab-case, PascalCase, camelCase, snake_case) и в импортах.
3. Переименование файлов: новый файл (newFiles) + удаление старого содержимого — отдельной задачей после обновления импортов.
