Обновление зависимостей.

1. Обновлять по одной библиотеке на задачу; версия — в install у задачи (программа поставит), код правится под изменения API этой версии.
2. Мажорная версия — сначала прочитать, что изменилось (заметки о выпуске в node_modules/<пакет>/CHANGELOG.md, если есть).
