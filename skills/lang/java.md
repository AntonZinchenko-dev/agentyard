Java:
- Пакет файла совпадает с папкой (package com.x.y;), класс — с именем файла.
- Импорты — явные, без *; неиспользуемые не оставлять.
- Spring: внедрение зависимостей через конструктор; логика в @Service, не в контроллере.
- null: проверки или Optional — как в проекте.
- Тесты — JUnit 5 (@Test, assertEquals) в src/test/java тем же пакетом.
