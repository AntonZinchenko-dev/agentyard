React / TSX:
- Компоненты — функции; хуки только на верхнем уровне компонента, не в условиях и циклах.
- В списках — стабильный key (id), не индекс.
- Next.js App Router: файлы с хуками и обработчиками событий начинаются с 'use client'; в app/layout.tsx 'use client' НЕ ставить (там export const metadata).
- className, не class; htmlFor, не for; стили — через классы общего CSS или UI-кита, без инлайн-стилей ради одной страницы.
- Если меняешь JSX-тег (<table> → <Table>), закрывающий тег меняется тоже, и импорт компонента добавляется.
