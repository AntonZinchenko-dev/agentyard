Go:
- Неиспользуемые импорты и переменные — ошибка компиляции: убирай их сразу.
- Ошибки возвращаются вторым значением и проверяются: if err != nil { return …, fmt.Errorf("…: %w", err) }.
- Экспортируемое — с заглавной буквы; пакет файла — как у соседних файлов в папке.
- Форматирование — как gofmt (табуляция для отступов).
- Тесты — файл *_test.go, func TestXxx(t *testing.T), табличные случаи.
